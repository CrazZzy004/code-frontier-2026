# CODE FRONTIER 2026 — лендинг IT-конференции

Одностраничный сайт мероприятия. Демо-работа для портфолио.

## Стек
- Чистый **HTML5 / CSS3 / vanilla JavaScript** — без сборки, без зависимостей, без внешних CDN.
- Работает офлайн: достаточно открыть `index.html` двойным кликом.

## Что внутри
- Адаптивная вёрстка (mobile-first, CSS Grid/Flexbox).
- Обратный отсчёт до старта (JS-таймер).
- Переключение дней в расписании (табы).
- Аккордеон FAQ, бургер-меню, плавный скролл по якорям.
- Reveal-анимации на скролле через `IntersectionObserver`.
- Индикатор прогресса чтения, «липкий» хедер.
- Уважает `prefers-reduced-motion`.

## Структура
```
event-devconf/
├── index.html      # разметка и контент
├── styles.css      # тёмная техно-минимал тема, адаптив
├── script.js       # таймер, меню, аккордеон, табы, reveal
├── assets/
│   └── favicon.svg
└── README.md
```

## Запуск
Открыть `index.html` в браузере. Для локального сервера (по желанию):

```bash
npx serve .
```

## Дизайн
Тёмный техно-минимализм: моно-типографика для акцентов, один бирюзовый акцент,
сетка-грид в hero, сдержанный glow как «данные», а не украшение.

> Тексты, спикеры и цены — вымышленные, для демонстрации.
